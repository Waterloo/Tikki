# Giggle ticketing system

- Read `CONTEXT.md` when you need a domain term or its exact meaning (glossary).
- Read `docs/DECISIONS.md` when you check why a rule exists; rows are numbered, for example `8.4`.
- Read `docs/architecture.md` before you change `server/`: the choke points and the one function to call for each.
- Read `docs/agents/parallel-work.md` when you work in a worktree next to other agents, or write a migration.
- Read `docs/issues/` for the issue you build: acceptance criteria and notes for later issues.
- Read `CODING_STANDARDS.md` when you review a diff.
