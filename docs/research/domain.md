# Domain name for Tikki

Date of checks: 2026-10-18. This is research only. Nothing was bought, registered, or contacted.

## Recommendation

| # | Name | Why |
|---|---|---|
| 1 | **tikki.run** | Available. $21.20 per year at Cloudflare. The exact name. "Run" fits the pitch: one Worker, nothing else to run. Good for a developer tool. Price is the same at renewal. |
| 2 | **gettikki.com** | Available. About $10.46 per year at Cloudflare. A .com is the safest choice for people who type the name from memory. "get" is a normal prefix for open-source tools. Pick this if you want the lowest risk. |
| 3 | **tikki.sh** | Available. $45 per year at Cloudflare. Short and familiar to developers, but it costs the most. Best if you plan a CLI or an install script. |

Notes for the decision:

- All three can be used at the same time for DNS on Cloudflare. A good plan: buy tikki.run for the website and docs, and add gettikki.com only if you want a .com for email and trust.
- Do not buy `tikki.page` or `tikki.fyi` as the main name. They are cheap ($10 and $5), but they look like a side project.
- The best exact names are taken: tikki.dev, tikki.app, tikki.io, tikki.co, tikki.com, tikki.ai. See the table.
- **Question for the owner:** `tikki.app` (registered at Cloudflare, 2026-03-24) and `tikki.dev` (registered at Name.com, 2026-06-11) are both new registrations with no site. Check if they are yours. If yes, use them and skip the rest.
- **Conflict:** a German ticket system named TIKKI exists (Ascora GmbH). See "Conflicts". It is a small risk for the name, not for the domain.

## Conflicts

Search was done on 2026-10-18. This is not legal advice. I did not search the USPTO, EUIPO, or IPOS trademark databases. Do that before you commit to the name.

- **TIKKI, ticket system by Ascora GmbH (Germany).** A product page describes "the ultra-modern ticket system TIKKI" for customer enquiries. This is the same name and the same category. It looks small and is in German. This is the most important finding. Source: [ascora.de/products/tikki](https://ascora.de/products/tikki/).
- **Tikkie (ABN AMRO).** A Dutch payment-request app. The spelling is close and it is a large brand, but the category is different (payments). Many GitHub repos use the name (for example `php-tikkie`).
- **tikki.team** shows a German login page named "Tikki". It is not clear what it does.
- **Similar names:** Tikit (Cireson, a ticket system for Microsoft Teams), TikiDesk (a ticket tracker), Tiki Wiki CMS (the Tiki Software Community Association holds the "Tiki" and "TikiWiki" marks). Source: [Justia, Tiki Community Software Association](https://trademarks.justia.com/owners/tiki-community-software-association-2210242).
- **npm:** the package `tikki` exists (v3.0.2, "Minimalistic game/animation loop orchestrator", by niklasramo). So the name `tikki` is not free on npm. Use a scope or another name for any npm package. Source: [npmjs.com/package/tikki](https://www.npmjs.com/package/tikki).
- **PyPI:** the package `tikki` exists (a Finnish reservist sports app). Source: [pypi.org/project/tikki](https://pypi.org/project/tikki/).
- **GitHub:** the user account `tikki` exists (id 601529). No org named `tikki` was found (API 404). The repo `niklasramo/tikki` is the game loop library. The project repo is `Waterloo/Tikki`.

## Limits of this research

- RDAP "not found" means unregistered today. Another person can register the name before you.
- Prices change. .com wholesale prices may rise on 2026-11-01 (one source says so).
- Cloudflare may reject a name at checkout for reasons I cannot see from outside (premium or reserved).
